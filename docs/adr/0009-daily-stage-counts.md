# ADR-0009: 기능별 하루 요청 건수

- 상태: proposed (#221, 운영자 병합 승인 대기)

운영자는 PostHog에 동의하지 않은 이용까지 포함한 서비스 규모를 확인해야 한다. 서버에서 이미 처리한 추천 계산, 방 생성, 참여, 역 지정에 대해 한국 날짜와 단계별 합계를 기한 없이 보관한다. 운영자만 DB에서 직접 조회한다. 배포 점검과 공유 미리보기 계산은 제외한다.

하루 한두 건인 단계도 그날 누군가 기능을 썼다는 사실만 드러낸다. 요청 본문, 식별자, 접속 시각을 남기지 않아 합계에서 개인의 이용 이력을 복원할 수 없다. 합계를 다른 자료와 연결하거나 차원·조회 대상을 늘릴 때는 이 판단과 보유 기간을 다시 검토한다.

집계 때문에 서비스가 느려지지 않도록 요청 시점의 날짜와 단계만 메모리 큐에 넣는다. DB 장애, 큐 포화, 인스턴스 종료 때 일부 건수가 빠질 수 있다.
