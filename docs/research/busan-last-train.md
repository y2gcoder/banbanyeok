# 부산 막차 빈칸 재조사 (#180, 2026-11)

조사일 2026-11-26(아래 "확인"은 모두 이 날짜). 조사만 했고 코드·설정·데이터 산출물은 바꾸지 않았다. 키가 필요한 API(TAGO, B5, B6)는 부르지 않았다. 정보공개청구·기관 문의도 하지 않았다. 공개 파일은 저장소 밖 임시 폴더에 받아 열었고 커밋하지 않았다(해시는 6절).
**[확인]**은 직접 받아 열거나 계산한 것, **[추론]**은 확인한 사실에서 이끌어 낸 것이다. 법률 판단은 하지 않았다. 앞선 조사는 [busan.md](busan.md)이고, 막차 규칙은 [last-train-design-fable.md](last-train-design-fable.md)와 `data/config/last-train.json`이다.

## 결론

운영자 질문은 "막차 데이터가 없는 게 아니라 환승 데이터가 없는 거라면 더 조사해 볼 수 있지 않나"였다. 조사해 보니 **환승 보행시간은 막차를 막는 가장 큰 빈칸이 아니다.** 더 큰 빈칸은 **시각표가 현행판인지**다.

1. **환승 원천이 있다.** 부산교통공사 역간 거리·소요시간 API(B6, data.go.kr 15158989)의 환승 행(`exchange=Y`)에 12개 환승역의 거리·시간이 있다. busan.md 1절의 "B6에는 보행 필드가 없다"는 틀렸다. 같은 `time`·`dist` 필드에 환승 값이 들어 있다. 다만 값은 분 단위 운영 기준값이고 역마다 하나뿐이다. 키가 필요해 이번에는 직접 받지 못했다. 값은 다른 공개 저장소의 2026-11-24 수집본에서 읽었다(1절).
2. **보수적 여유 규칙은 안전하고, 손해는 환승 데이터가 아니라 여유의 최솟값이 정한다.** 지금 설계 규칙 `max(10분, 걷는 시간×2 + 5분)`을 B1 열차번호 시각표에 적용했다. 그 결과 1~4호선 내부 환승 6역의 여유가 공개된 가장 긴 휠체어 동선을 0.8 m/s로 걷는 시간보다 모두 길었다(2절). 서울 기본값(89·221초)을 쓰든 B6 값을 쓰든 막차는 거의 같게 나온다(평일 영향 칸 6,580 대 6,636, 중앙값 15분 이름). 일률 20분 상한은 중앙값 26분, 30분 상한은 32분 이르게 나와 쓸모가 크게 떨어진다.
3. **1~4호선 B1(2026-07-22)은 토요일·휴일에 낡은 판이다.** 부산교통공사가 [2026-08-24부터 1~4호선 토요일·휴일 시각표를 바꿨다](https://www.humetro.busan.kr/homepage/default/board/view.do?board_no=26088C3X3L&conf_no=80&menu_no=1001040101). 평일은 1·3호선 일부 역만 1분 안팎 조정됐다. 첫차·막차는 같다고 공지했다. 공지 첨부(열차번호별 전 역 시각, 이하 H1)와 맞춰 보니 역·행선지별 막차가 1·3호선에서 모든 요일 100% 같았다. 낮 열차는 주말에 크게 달랐다(3.1절).
4. **동해선은 풀렸다.** 저장소가 #191에서 받은 TAGO(2026-11-25)와 코레일 2026-09 시각표(K2, 열차번호 있음)가 평일 2,176건, 휴일 1,968건 모두 **초까지 같다.** 막차도 평일 66/66, 휴일 63/63 같다(3.2절). 남은 것은 K2를 대조용으로 써도 되는지에 대한 운영자 결정이다.
5. **4호선 공휴일은 풀렸다.** 운영사 누리집의 4호선 시각표 탭은 '평일·토요일·일/공휴일'이고, H1의 4호선 시트 이름도 '휴'다. B1의 '일요일'은 일·공휴일 표다(3.4절).
6. **계속 끄는 칸**: 동해선·부산김해 토요일(원천 없음), 부산김해 전체(현행 열차번호 원천 없음, 운영사 표 두 개가 1분씩 다름), 부산김해 환승(사상·대저), 2호선 양산중앙 개통(2026-12) 뒤 판.

| 1·3호선 평일 직행 | **켤 수 있음** | 구현(5.2 PR 6). H1을 대조용으로 쓰는 운영자 결정 |

수도권 막차에 번지지 않는 조건(busan.md 5.2 PR 6: 권역 단위 신선도·끄기, 양방향 테스트)은 모든 칸의 전제다.

### 1.1 서울 S4는 어떤 원천이었나 [확인]

S4는 서울 열린데이터광장의 [서울교통공사 환승역거리 소요시간](https://data.seoul.go.kr/dataList/OA-13290/S/1/datasetView.do)이다. 140행, 2025-03-31 파일, 공공누리 1유형이다. 공식 설명에 따르면 시간은 **환승거리를 1.2 m/s로 나눈 참고치**다(`docs/research/data-sources.md`). 실측이 아니고 대기·혼잡·엘리베이터는 들어 있지 않다. 그러니 부산에서 같은 종류를 찾는다는 것은 "운영사가 낸 역별 환승 거리와 표준 시간"을 찾는다는 뜻이다.

### 1.3 얻을 수 없는 것

방향·승강장별 환승 시간(서울 15098252처럼 칸·문에서 칸·문까지)은 부산에 공개된 것이 없다. 이것이 필요한 이유는 막차 여유를 줄이는 것뿐이다. 2절대로 여유의 최솟값 10분이 손해를 정하므로, 방향별 값을 얻어도 막차가 늦어지는 칸은 적다 [추론: 2절 수치]. 정보공개청구(5절)는 이 값의 근거를 받는 용도로 둔다.

## 2. 보수적 여유로 안전을 보장할 수 있나

### 2.1 계산 방법 [확인]

- 입력: B1(1~4호선 열차별 시각표, 2026-07-22). 결함 열차 6대는 파이프라인과 같은 기준으로 뺐다(평일 2, 공휴일 4). 역은 이름으로 맞췄고 108개다(4호선을 뺀 공휴일은 96개).
- 탐색: 열차번호로 묶은 구간을 출발 시각이 늦은 순서로 훑는 역방향 탐색이다. 집 역 H마다 "역 S에서 몇 시에 타면 H에 닿는가"의 가장 늦은 출발을 구한다. 같은 노선에서 다른 열차로 갈아타면 10분, 다른 노선으로 갈아타면 아래 정책의 여유를 둔다. 첫 열차를 탈 때는 여유가 없고, 10분 단위 내림은 하지 않았다.
- 범위: 1~4호선 안의 경로만 본다. 동해선·부산김해를 지나야 더 빠른 칸은 이 계산에서 더 이르게 나온다(안전한 쪽).
- 기준값(`walk_b6`): 여유 없이 B6x 시간만큼만 걷는다고 본 막차다. 현실보다 늦을 수 있는 낙관값이며, 각 정책이 이것보다 몇 분 이르게 나오는지를 잰다.

| 정책 | 환승 여유 |
|---|---|
| `rule_seoul` | `max(10분, w×2+5분)`, w = 지금 부산 미리 보기 값(기본 89초, 동래·연산·서면 221초) |
| `rule_b6` | 같은 식, w = B6x 값 |
| `flat20` / `flat30` | 다른 노선 환승마다 20분 / 30분 |

| 미남 | 240초 | 780초 | 158 m | 198초 |
| 동래 | 360초 | 1,020초 | 551 m | 689초 |

휠체어 동선 거리는 엘리베이터 대기를 거리로 바꿔 넣은 값이다(busan.md 1절). 그것을 S4의 1.2 m/s보다 느린 0.8 m/s로 걸어도 모든 역에서 여유가 더 길다. `rule_seoul`도 모두 통과한다(가장 빠듯한 동래 742초 대 689초). **내부 6역은 지금 규칙으로 '이른 쪽' 조건을 지킬 수 있다** [추론]. 보장하지 않는 것은 설계 문서 2.3절과 같다. 여유보다 큰 지연, 수집 뒤 개정, 운행 중단은 막지 못한다. 그중 개정은 3절이 다룬다.

운영사 간 환승(교대·거제·벡스코·부전·사상·대저)에는 이런 대조 근거가 없다. 켤 때는 B6x와 #198의 480초 중 큰 값을 w로 쓴다(여유 21분).

### 2.3 쓸모는 얼마나 떨어지나 [확인]

S ≠ H인 모든 역 쌍을 봤다. "영향 칸"은 `walk_b6`보다 이르게 나온 칸이다. 괄호 안은 후보 27역에서 출발하는 칸이다.

| 요일 | 쌍 | 직행만으로 막차가 정해지는 쌍 | 정책 | 영향 칸 | 영향 칸의 이른 정도 중앙값 / p90 | 최대 |
|---|---:|---:|---|---:|---:|---:|
| 평일 | 11,556 (2,140) | 3,770 | `rule_seoul` | 6,580 (1,080) | 15 / 20분 | 29분 |
| | | | `rule_b6` | 6,636 (1,072) | 15 / 20분 | 29분 |
| | | | `flat20` | 7,245 (1,201) | 26 / 35분 | 51분 |
| | | | `flat30` | 7,614 (1,280) | 32 / 50분 | 66분 |
| 토요일 | 11,556 | 3,690 | `rule_b6` | 6,887 | 15 / 20분 | 34분 |
| | | | `flat20` | 7,565 | 26 / 33분 | 51분 |
| 공휴일(4호선 제외) | 9,120 | 3,508 | `rule_b6` | 4,817 | 15 / 18분 | 34분 |
| | | | `flat20` | 5,532 | 26 / 33분 | 51분 |

- 모든 정책에서 `walk_b6`보다 늦게 나온 칸은 0, 길을 잃은 칸도 0이다.
- `rule_seoul`과 `rule_b6`은 영향 칸 수가 평일 56칸 다를 뿐이고 분포는 같다. 대부분의 환승에서 여유가 최솟값 10분으로 정해지기 때문이다. **환승 데이터를 더 정밀하게 얻어도 막차가 늦어지는 칸은 적다.**
- 일률 상한은 쓸모를 크게 깎는다. 20분 상한이면 영향 칸의 중앙값이 15분에서 26분으로 는다. 예를 들어 평일 서면→미남은 `walk_b6` 24:01, `rule_b6` 23:46, `flat20` 23:34, `flat30` 23:22이고, 센텀시티→안평은 23:36, 23:20, 23:07, 22:41이다.
- 권고: 상한 방식 대신 **지금 규칙 `max(10분, w×2+5분)`을 B6x 값으로 쓴다.** 휠체어 실측 대조(2.2절)를 발행 게이트에 넣어 B6x 값이 바뀌어 여유가 실측 동선보다 짧아지면 끈다.

### 3.1 1~4호선 시각표의 현행성 [확인]

- 첨부 H1 `1~4호선 열차운행계획(2026.8월 이후, 홈페이지용).xlsx`: 노선마다 역정보, 평·토·휴 시트가 있고 열차번호별 역 시각이 초 단위로 있다. 한 시트에 상선·하선 묶음이 나란히 있다. 사이트 하단 표기는 `ⓒ 2025 Busan Transportation Corporation. All Rights Reserved.`이고 공공누리 표시는 보지 못했다.

**H1과 B1 대조.** 판이 바뀌며 열차번호가 다른 열차에 다시 붙었다(같은 번호인데 30~170분 차이). 그래서 번호가 아니라 (노선, 요일, 역, 행선지)별 시각 묶음으로 맞췄다. B1은 도착 분, H1은 초를 버린 분이다.

- 1·3호선은 공지와 맞는다. 평일은 거의 같고 주말은 낮 열차가 달라졌지만, 막차 칸은 모든 요일에서 같다.
- 4호선은 다른 1칸(안평→미남)에서 H1이 B1보다 1분 늦다. 즉 B1이 이른 쪽이다. 4호선 평일이 65.5%만 같은 것은 공지("해당 없음")와 맞지 않는다. B1에는 H1에 없는 열차가 요일마다 20대 더 있다. 원인은 확인하지 못했다.

- 운영사 누리집의 역별 시각표(남포·장산·미남·안평 4쪽, 15초 간격으로 받음)도 평일은 남포 177/177·미남 160/160이 B1 도착 분과 같았고, 네 역 모두 행선지별 막차가 B1과 같았다.

**영향.** B1만으로는 토·휴일의 환승 막차를 낼 수 없다. 환승은 막차가 아닌 열차의 시각에 기대는데, 그 시각이 바뀌었기 때문이다. 직행 막차 칸은 H1과 칸마다 대조해 통과한 칸만 낼 수 있다. 신선도 규칙도 바뀌어야 한다. 지금 120일 규칙은 수집일 기준이라 B1을 다시 받기만 해도 새것처럼 보인다(busan.md 위험 4). 신분당의 `latest_timetable_change`처럼 **운영사 공지의 최신 시행일 ≤ 원천 기준일**을 조건으로 둔다. B1(07-22)은 공지 시행일(08-24)보다 앞서므로 토·휴일 환승에는 쓸 수 없다.

현행 계산 원천의 후보는 셋이다. ① H1(현행·열차번호·초 단위. 이용 조건 불명확. 대조용 또는 "두 번 계산해 이른 쪽"으로만 쓴다), ② B5 [열차시각표 조회 서비스_GW](https://www.data.go.kr/data/15158990/openapi.do)(열차번호 있음, 제한 없음, 키 필요. 현행판인지 확인 필요), ③ data.go.kr B1의 다음 판(차기 등록 2027-07-31). 운영자가 포털 [데이터 개선요청](https://www.data.go.kr/data/15082980/fileData.do)으로 8-24 판 등록을 요청하는 방법도 있다.

### 3.2 동해선 [확인]

#191이 받은 TAGO(`data/raw/tago-busan/`, 2026-11-25 수집)와 K2(코레일 동해선 시각표, 2026-09-01판)를 역·행선지·출발 초로 견줬다. TAGO의 `거제(법원.검찰청)`을 `거제`로, K2의 약칭 다섯 개를 정식 이름으로 맞췄다.

| 평일(01) | 2,176 | 2,176 | **2,176** | **66/66** |

- 남은 결정: K2의 재사용 조건은 불명확하다(busan.md 1절, 코레일 저작권정책에 공공누리 4유형 문구가 함께 있음). 신분당(#64)처럼 **원문은 커밋하지 않고, TAGO 줄에 열차번호를 붙이거나 칸마다 대조하는 데만 쓰는 것**을 운영자가 허락하면 평일·휴일 직행을 켤 수 있다.

### 3.3 부산김해경전철 [확인: #191 대조 결과]

- TAGO(01·03)와 운영사 첫차·막차 표 O1은 막차가 평일 40/40, 휴일 38/40 같다. 나머지 2건은 TAGO가 1분 이르다.
- 운영사 역별 전체 시간표 O2(6역 10조합)와는 막차가 4/10 같고, 나머지는 **TAGO가 1분 늦다.** O1과 O2가 서로 1분씩 다르다.
- 현행 열차번호 원천이 없다(K1은 2022판, TAGO 막차가 K1보다 14~17분 늦음). 지금 규칙(`rebuild` 꺼짐)으로는 신분당 방식, 즉 TAGO 직행 + 운영사 표본 칸 대조만 가능하다. O1·O2의 1분 차이와 적용일을 운영사(부산김해경전철㈜, 민간이라 정보공개법 대상이 아니다)에 확인하기 전에는 켜지 않는다.

### 3.4 토요일과 4호선 공휴일 [확인]

- **토요일.** 1~4호선은 B1·H1 모두 토요일 표가 따로 있다(다만 B1은 낡은 판, 3.1절). 동해선·부산김해는 TAGO 02의 88개 응답이 모두 비었다. K2는 평일·휴일 두 종이고, 9-1 공지도 토요일을 말하지 않는다. 설계 2.5절대로 운영사가 "토요일에 휴일 표"라고 밝힌 출처가 생기면 `saturday: "holiday"`로 켤 수 있다. 그전에는 끈다.
- **4호선 공휴일.** 부산교통공사 누리집 4호선 안평역 시각표의 탭이 `평일 / 토요일 / 일/공휴일`이고, H1의 4호선 시트 이름도 `휴(258회)`다. B1의 4호선 `일요일`은 일·공휴일 표로 보고 holiday에 대응시킬 수 있다. 다만 그 표도 8-24에 바뀌었으므로 3.1절의 조건을 같이 따른다.
