# W24 — 귀갓길 막차 안내 2차: 화면 (#62)

검증일 2026-11-21. 1차(파이프라인·서버·계약)는 [w21-notes.md](w21-notes.md), API는 [openapi.yaml](../../contracts/openapi.yaml)의 `LastTrain`·`LastTrainBasis`다. 이 PR은 웹만 바꾼다. 서버·계약·데이터·처리방침 파일은 그대로다.

## 1. 무엇이 보이나

결과 화면과 방 화면의 후보 카드(1위는 펼친 채, 2·3위는 펼쳤을 때)에 **"집에 가는 막차"** 칸이 생긴다. 추천 이유 아래, 지도 한가운데 비교 표 위다. 가는 길(사람별 시간 막대)과 섞지 않는다.

| 줄 | 보이는 말 | 근거(API) |
|---|---|---|
| 맨 위 한 줄 | "지연은 23시 전에 나서야 해요" | 출발역을 공개한 사람 가운데 화면에 보이는 시각이 가장 이른 사람. 시각을 아는 사람이 없으면 줄이 없다 |
| 직행 확정 | "막차 00:03 `다음 날` · 광교행" / "강남역에서 열차가 떠나는 시각이에요." | `kind=direct`. 분 그대로, 행선지는 `boundFor`만 |
| 여유 시각(갈아타는 길) | "늦어도 22:20엔 출발하세요" / "갈아타는 길이라 넉넉히 일찍 잡았어요. 실제 막차는 이보다 늦을 수 있어요." + 버튼 | `kind=margin`, `transfer=true`. **10분 단위로 내림** |
| 여유 시각(열차 한 대) | "늦어도 23:40엔 출발하세요" / "인천행 열차 한 대로 가요. 시간표를 한 번 더 맞춰 보기 전이라 넉넉히 일찍 잡았어요. 실제 막차는 이보다 늦을 수 있어요." + 버튼 | `kind=margin`, `transfer=false` |
| 확인 필요 | 시각 없이 이유 한 줄 + 버튼 | `kind=check`. 이유는 아래 표 |
| 출발역이 바로 그 역 | "출발역이 바로 이 역이에요." (버튼 없음) | 그 사람의 출발역 코드 = 후보 역 코드 |
| 숨긴 사람(다른 사람 화면) | 줄 없음. 칸 아래에 "출발역을 숨긴 분의 막차는 본인 화면에서만 보여요." | 서버가 항목을 주지 않는다 |
| 숨긴 사람(본인 화면) | 내 줄이 보이고 이름 옆에 "나에게만 보여요" | `participants[].hidden` + `isSelf` |
| 일부 노선 | "토요일은 일부 노선만 막차를 보여 드려요." | `lastTrainBasis.partial`이고 시각이 빠진 줄이 있을 때 |
| 공통 안내 | "2026년 11월 16일 시간표로 계산했어요. 공사나 행사가 있으면 달라질 수 있으니 타기 전에 한 번 더 확인해 주세요. 승강장까지 걷는 시간은 따로 잡아 주세요." | `lastTrainBasis.asOf` |

확인 필요의 이유(칸 안의 모든 확인 필요 줄이 같은 이유다. 어느 노선 때문인지는 API에 없어 노선 이름을 적지 않는다).

| 근거 | 말 |
|---|---|
| `unavailable=stale` | 시간표가 오래돼 확인이 필요해요. |
| `unavailable=date_out_of_range` | 이 날짜는 공휴일인지 아직 알 수 없어 막차를 보여 드리지 못해요. |
| `unavailable=day_unknown` (약속 날짜 없는 방) | 약속 날짜가 없어 요일을 알 수 없어요. 요일마다 막차가 달라요. |
| `partial`인 토요일 | 이 길의 토요일 막차는 아직 준비 중이에요. |
| 그 밖 | 이 길은 아직 막차를 계산하지 않아요. |

- **버튼 "지도 앱에서 막차 확인하기"**: 여유 시각과 확인 필요에만 둔다. 카카오맵 대중교통 길찾기를 **만날 역 → 그 사람의 출발역** 방향으로 연다(`kakaoTransitUrl`의 인자 순서만 바꿨다). 누를 때만 새 탭으로 열리고 통계 이벤트는 보내지 않는다. 지도 앱 링크로는 막차나 출발 시각을 정할 수 없어 "정확한 막차"라고 적지 않았다.
- **옛 링크(v=1)**: 칸 자체가 없다. 요일을 고른 적이 없는 링크라 서버도 시각을 주지 않는다(`day_unknown`). 결과 화면이 `ShareState.slotDefaulted`를 보고 `toResultView(…, { lastTrains: false })`로 뺀다.
- **막차를 모르는 응답**(`lastTrainBasis` 없음: 표를 읽는 중이거나 검증 실패): 칸이 없다.
- **문구는 한 곳**(`web/src/lib/result/last-train.ts`)에서 만든다. 화면 구성요소는 `web/src/components/result/last-trains.tsx`다. "AI"·"손해"·"억울"·"정확한"이 없음을 테스트가 본다.

## 2. 공유 그림

| 그림 | 바뀐 것 |
|---|---|
| 공유 링크 숫자판(`/s/og`) | 사람마다 큰 시간 아래 작은 줄: 직행 확정 "막차 00:03", 여유 시각 "늦어도 23:00". 확인 필요면 줄이 빈다. 한 사람도 시각이 없으면 줄 자리를 잡지 않아 그림이 예전과 같다(옛 링크 포함). 줄이 생기면 큰 숫자를 12% 줄이고 위아래 틈을 좁혀, 맨 아래 문장이 두 줄이어도 넘치지 않는다 |
| 방 미리보기 카드(`/r/<id>/og`) | 각자의 노선 바로 아래에 같은 줄(작게). 출발역을 숨긴 사람은 서버가 막차를 주지 않아 줄이 없다 |

- 그림 버전 `SHARED_OG_IMAGE_VERSION`을 `97b100f4` → `619d69ea`로 올렸다(숫자판). 글꼴 서브셋은 다시 만들어도 같았다("막차"·"늦어도"·숫자·쌍점이 이미 들어 있었다). 그래서 사이트 기본 그림·역 조합 그림의 버전은 그대로다.
- 방 미리보기 카드는 주소에 그림 버전이 없다(`sv`·`dv`뿐). 공유할 때마다 방의 공유 번호가 붙으므로 새로 보내는 메시지는 새 그림을 받는다. 번호가 바뀌지 않은 방을 다시 보내면 카카오가 캐시한 옛 그림(막차 줄 없음)이 나올 수 있다.

## 3. 미리보기 설명과 공유 문구: 넣지 않았다

`og:description`과 공유 시트·카카오톡 메시지 설명(같은 말)에는 막차를 넣지 않았다.
- **길이.** 지금 설명이 이미 "민수 34분 · 지연 38분 · 공평하게 고름 · 토요일 저녁 기준 · 지도 한가운데인 한강진역이면 잠실은 14분 더 걸려요"까지 간다. 카카오톡 말풍선은 설명을 두 줄 남짓에서 자른다. 막차를 붙이면 잘려서 보이지 않거나 앞의 말을 밀어낸다.
- **그림에 이미 있다.** 같은 말풍선의 그림에 사람별 막차 줄이 있다.
- **고칠 수 없다.** 메신저가 한 번 만든 미리보기는 바꾸지 못한다. 막차는 시간표가 바뀌면 달라지는 값이라, 설명 없이("넉넉히 잡았다"·기준일) 글로만 남는 것은 피했다.

- 가짜 서버(`web/mock/recommend.ts`)가 꾸민 막차를 준다(실제 시간표가 아니다). 방은 e2e 픽스처(`e2e/support/room-fixture.ts`)에 `hidden-self` 시점을 더했다.
- 기존 검사 넷을 새 화면에 맞췄다: 이름·"(나)"가 시간 줄과 막차 칸 두 곳에 나오는 것(`flow`, `real-server`, `rooms`), 옛 링크와 새 링크의 카드 글 비교에서 막차 칸을 빼는 것(`time-slots`), 시점 표현 검사가 "떠나는 시각"의 "나는"에 걸리지 않게 한 것(`real-server`).

## 5. 처리방침

이 PR은 `web/src/app/privacy/policy.ts`를 고치지 않는다. 방 링크 미리보기 그림에 공개한 참여자의 막차 시각이 더해지므로 6항 설명 보완이 필요하다(문구 초안은 PR 본문). 2026-11-28에 시행되는 새 15항의 1단계(설명 보완, 바로 시행)로 병합 직전에 반영한다.
