# 반반역

> 우리 어디서 만나야 덜 억울할까?

- 공평하게 / 빨리 만나기 / 오늘은 ○○ 쪽으로 — 세 가지 기준
- 사람별 소요시간·환승 횟수·추천 이유를 그대로 보여줍니다
- 설치·가입 없이 링크로 공유

현재 설계 단계입니다. 결정 사항은 [docs/01-synthesis.md](docs/01-synthesis.md)를 보세요.
